# 차량 트래킹 기반 속도 및 방향 추정 모듈

이 프로젝트는 자율주행 차량 환경을 가정하여 **연속 프레임의 차량 위치 정보를 기반으로 속도와 이동 방향을 추정**하는 모듈을 직접 개발한 결과입니다.

---

## 📁 구성 파일

- `vehicle_tracker.py` : 차량 속도 및 방향 계산을 위한 핵심 클래스 모듈
- `run_tracking.py` : 입력 이미지 폴더에서 차량을 탐지하고 추적하는 실행 코드
- `tracking_result.mp4` : 결과 영상 (차량 중심 좌표, 속도 및 방향 표시 포함)
- `README.md` : 프로젝트 설명 및 참고 이론 정리

---

## 🧠 과제 설명

**과제명:** 트래킹 기반 속도/방향 계산 모듈 구현  
**요구사항:**
- 오픈소스 트래커 사용 금지
- 직접 계산한 차량 위치 변화 기반 속도 추정
- 방향은 각도로 표기
- 픽셀 → 실제 거리 변환을 위한 캘리브레이션 계수 활용

---

## ⚙️ 처리 순서 요약

1. 이미지 프레임을 순차적으로 불러옴
2. 밝기 기반 차량 탐지 → 중심 좌표 저장
3. ID별 위치 추적 (deque 이용)
4. 이전 프레임과 현재 프레임 간 거리 및 시간 변화 계산
5. 속도 (m/s) 및 방향 (deg) 계산
6. 프레임에 결과 표시 → 영상 저장

---

## 🔍 결과 예시

- ID 0 | 6.2 m/s | 45.0°
- ID 1 | 2.4 m/s | 90.0°
- 등속 이동 차량과 곡선 이동 차량 모두 표시 가능

## 🧠 공부한 컴퓨터 비전/영상처리 개념

### 📌 1. IOU (Intersection over Union)

- 두 박스가 얼마나 겹치는지 측정하는 값 (0~1 사이)
- 트래킹에서 동일 객체 판단 기준에 사용됨

### 📌 2. 픽셀-실거리 변환 (Calibration)

- 실제 거리(m) = 픽셀 거리 × 변환계수 (예: 0.05 m/pixel)
- 보통 영상 촬영 위치, 카메라 사양에 따라 측정

### 📌 3. 속도 계산

- `speed = distance / time`
- 프레임 간 시간 = 1 / FPS
- 거리 = √(Δx² + Δy²) × 변환계수

### 📌 4. 방향 계산

- `atan2(dy, dx)` 함수로 계산
- 라디안 → 도(degree)로 변환 필요

### 📌 5. `deque` 활용

- 프레임별 차량 위치를 2개만 저장해서 속도 계산
- 메모리 낭비 방지
