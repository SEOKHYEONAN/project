
# 🛣️ YOLOv8 + Norfair 기반 교통사고 예측 시스템

이 프로젝트는 YOLOv8 객체 탐지기와 Norfair 트래커를 기반으로, 교통사고 유튜브 영상에서 차량을 탐지 및 추적하고, 선형 경로 기반 속도 및 방향 계산을 통해 **충돌을 사전에 예측**하는 실험적 모듈입니다.

---

## 📁 구성 파일

- `predict_collision.py` : 영상에서 차량 탐지 및 추적 후, 선형 경로 기반 충돌 시간 계산 및 시각화
- `videoplayback.mp4` : Colab에 업로드된 원본 영상 파일 (20초 ~ 40초 범위 분석)
- `result_output.mp4` : 처리된 결과 영상 (충돌 경고 프레임 포함)
- `README.md` : 프로젝트 구조 및 기술 개념 요약 설명

---

## 📌 과제 목표

**과제명:** YOLO 기반 차량 추적 및 충돌 예측 시스템 개발  
**주요 기능:**
- YOLOv8을 이용한 차량 객체 탐지
- Norfair 트래커 기반 다중 차량 추적
- ID별 위치 정보로 속도 및 이동 방향 계산
- 선형 경로 기반 충돌 시간 계산
- 임계시간 이하 차량 쌍에 대해 충돌 경고 출력 및 결과 영상 저장

---

## ⚙️ 처리 절차 요약

1. 업로드된 영상에서 20초~40초 구간만 잘라서 처리
2. YOLOv8을 통해 차량 탐지 및 클래스 필터링
3. Norfair로 다중 객체 추적 → 고유 ID 할당
4. 매 프레임마다 속도 및 방향 계산 (거리 변화 기반)
5. 각 차량 쌍의 충돌 예상 시간 계산
6. 임계시간 이하일 경우 log에 충돌 기록 + 프레임에 경고 표시
7. 최종적으로 처리된 영상을 `result_output.mp4`로 저장

---

## ⚠️ 충돌 예측 방식

- 차량 위치는 중심점 기준
- 속도: 현재 프레임과 이전 프레임 사이 거리 / 시간
- 선형 이동 가정:  
  `예상 위치 = 현재 위치 + 속도 × 시간`
- 충돌 시간 = 차량 간 거리 / 상대 속도  
  (단, 방향이 수렴하지 않으면 제외)

---

## 📐 주요 파라미터 및 설정

- `VIDEO_FILE = 'videoplayback.mp4'`
- `CONFIDENCE_THRESHOLD = 0.3`
- `DISTANCE_THRESHOLD = 30` (Norfair 매칭 기준)
- `COLLISION_TIME_THRESHOLD = 2.0초`
- `FPS = 30` 기준으로 20초~40초 → 프레임 범위 600~1200

## 🧠 적용한 영상처리 및 추적 개념

### 📌 1. YOLOv8 (Ultralytics)

- 클래스 'car', 'truck', 'bus', 'motorcycle'에 해당하는 객체만 사용
- 사전 훈련된 경량 모델 yolov8n 사용

### 📌 2. Norfair 트래킹

- 유클리드 거리 기반 Matching
- `Detection` → `TrackedObject` 변환 후 ID 기반 추적

### 📌 3. 선형 예측 기반 충돌 시간 계산

- 차량이 현재 방향으로 동일하게 계속 이동한다는 가정 하에 거리와 상대 속도로부터 충돌 시간 계산

## 🧪 결과 예시

```
🚨 충돌 예상: 차량 3번과 5번, 1.4초 후 예상됨

```

영상 내 충돌 가능성이 높은 경우 경고 텍스트가 빨간색으로 프레임에 오버레이됨.

## 📝 참고 및 개선 사항

- 실제 주행 환경은 선형 경로가 아닐 수 있음 → 보정 필요
- 더 정확한 예측을 위해 속도 예측에 Kalman Filter 등 적용 가능
- 픽셀 → 실제 거리 환산 위한 보정 계수는 현재 적용하지 않음
- 더 정밀한 경고 시스템은 차량 크기, 방향각, 궤적 변화 등 추가 분석 필요
